# Retro Arcade Vault

A browser-based collection of classic retro games built with HTML, CSS, and JavaScript.

## Included games
- Snake
- Pong
- Breakout
- Tic-Tac-Toe
- Memory Match
- Tetris

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server, for example:
   ```bash
   python3 -m http.server 8000
   ```
3. Visit `http://localhost:8000` in your browser.

## Repo contents
- `index.html` — main page shell
- `styles.css` — arcade styling
- `app.js` — all game logic

## Notes
This project is intentionally self-contained and uses only browser-native JavaScript, so it loads quickly and works without installation.

## Downloading as ZIP
On GitHub, click the green `Code` button and choose `Download ZIP` to package the project as a zip archive.
